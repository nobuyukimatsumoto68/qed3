# qed3

- TO SETUP

$ source setup.sh

- geometry data for the refinement level L can be generated by

$ cd geometry

$ make

$ ./get_geometry.out L

$ ./simp.out L

$ ./dual.out L

- TO RUN (currently, compact U(1) on icosahedron)
$ ./a.out

Supply an argument to specify the Wilson coupling (e.g., $\beta = 1.4$):
$ ./a.out 1.4
