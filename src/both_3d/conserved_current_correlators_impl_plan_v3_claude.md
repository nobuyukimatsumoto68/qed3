# Plan v3: Conserved-Current Correlator Measurements

Canonical plan.  Supersedes `conserved_current_correlators_impl_plan_v1_claude.md` (scratch)
and `_v2_claude.md` (revision history); both retained for derivation/decision history.

Reference: A. Katz, N. Matsumoto, "Notes on QED3 (interacting theory)",
`/mnt/barracuda22/qed3/qed3int_v2-10.pdf` -- Secs. 3.3.1--3.3.4 (lattice correlators,
Eqs. 3.39--3.69), 4.2--4.3 (CFT estimators, Eqs. 4.27--4.36), App. C (real spherical
harmonics).

---

## 1. Goal and scope

Measure current-current two-point functions on the $S^2\times$time lattice using the exactly
conserved overlap currents.  Currents are two-component in the $\xi$/$\eta$ basis; the $(+)$
vector current is $J_{V,+}^{nn'}(t)=\eta_f^\dagger K^{nn'}(t)\xi_f$ (Eq. 3.36).

**Currents.**

- **Vector** $J_{V,\pm}$ -- connected $+$ disconnected.
- **Flavor** $J_{r,\pm}$ -- connected only, equal to the vector-connected piece; **does not
  exist for $N_f=2$** ($N_f=4,6$ only).
- **Axial** $J_{A,\pm}$ -- connected only; the two *mixed* orderings $C_{A_{+-}}$, $C_{A_{-+}}$;
  **no disconnected diagram**.

**Projected observables** (Sec. 4), each computed for each current:

- $G_s(t)$ -- spatial, equal-link average (Eq. 4.29).
- $G_t(t)$ -- temporal, site-diagonal (Eq. 4.32).
- $G^{t}_{\ell_1 m_1;\ell_2 m_2}(t)$ -- spherical-harmonic projection (Eq. 4.36), carrying the
  conformal tower (Eqs. 4.34--4.35): $\ell=0$ vanishes (charge conservation),
  $\ell=1\sim e^{-2t}$, $\ell=2\sim e^{-3t}$.

**Ensembles** (remote cluster, generated by `hmc_w_mass_claude.cu`).  Fixed: $g^2=8.0$,
$\nu_0=1.0$, $N_t=128$, `N_REFINE=1` ($L=1$).  Per $N_f\in\{2,4,6\}$: one **massless** plus
four **flavor-breaking** $m_F\in\{0.01,0.05,0.1,0.2\}$ (real) plus four **parity-breaking**
$m_P\in\{0.01,0.05,0.1,0.2\}$ (imaginary) -- 9 ensembles per $N_f$, **27 total**.  ($L=2$ is
deferred and out of scope; it will build on the $L=1$ work.)

### 1.1 Per-ensemble analysis matrix

"Sea" = the mass the gauge configs were generated with (selects which configs to read);
"valence" = the mass passed to the measurement executable (drives the propagators).  They are
decoupled and differ only in the $m_F$-axial cell.

| Ensemble (sea) | Vector (conn + disc) | Axial (conn only; no disc) |
|---|---|---|
| massless | valence $0$ | valence $0$ |
| $m_F$ (real) | valence $m_F$ -- exact massive current (Eqs. 3.58--3.60) | valence $0$ -- massless formulas (Eqs. 3.55--3.57) on the $m_F$ configs |
| $m_P$ (imag) | valence $m_P$ -- exact massive current (Eqs. 3.64--3.67) | valence $m_P$ -- exact massive current (Eqs. 3.68--3.69) |

Key facts that keep the executables simple:

- Only the **valence propagator mass** $m$ varies across cells (Sec. 2).  The kernel $K$ is
  always the same massless-form Noether kernel -- there is **no "kernel mass"**.  Any finite
  correction to $K$ in the massive theory is exactly compensated by a propagator factor (the
  $(1+m_P)^{-1}$ of Eq. 3.62), so the implemented traces use the standard $K$ with **no
  prefactor and no kernel branching**.
- Disconnected is **vector-only**.
- At finite $m_P$ all continuous symmetries stay intact, so the axial current is still exactly
  conserved; at finite $m_F$ it is not, hence the massless form.

A driver shell script (Chunk 10) holds this case logic: it iterates ensembles
$(N_f, g^2, \nu_0, \text{sea }m)$, points each executable at the sea config directory, and
passes the appropriate **valence** mass and `--current`.

## 2. Notation and operators

Fermionic contractions use the fermionic average $\langle\cdot\rangle_F$; $\langle\cdot\rangle_U$
is the gauge average, $^*$ complex conjugation.  There is **no $\gamma_5$-hermiticity**
($D_\text{ov}^{-\dagger}\neq\gamma_5 D_\text{ov}^{-1}\gamma_5$).  The overlap satisfies the
Ginsparg-Wilson relation $D_\text{ov}^\dagger D_\text{ov}=D_\text{ov}+D_\text{ov}^\dagger$
($D_\text{ov}=1+V$, $V$ unitary), so $D_\text{ov}+m$ is **normal** for any complex $m$.

**Operators (PDF symbols).**  With the valence mass $m=$ `Complex(mass_re, mass_im)`,

$$
D_m \equiv D_\text{ov}+m
\quad(\text{Eq. 3.60};\ m=0\text{ massless},\ m\in\mathbb{R}\ \text{is } m_F,\ m\in i\mathbb{R}\ \text{is } m_P),
$$

and, **for the parity case only**, the dagger-side operator (Eq. 3.63)

$$
\tilde D_{m_P}\equiv D_\text{ov}+\frac{m_P}{1-m_P}
$$

(a general complex shift, still coefficient 1 on $D_\text{ov}$).  The Wick contractions
(Eqs. 3.50--3.51, 3.58--3.59, 3.61--3.62) involve a **forward** and a **dagger** propagator:

$$
\langle\xi_f\,\eta_g^\dagger\rangle_F=\delta_{fg}\,D_m^{-1},
\qquad
\langle\eta_f\,\xi_g^\dagger\rangle_F=\delta_{fg}\times
\begin{cases}
D_m^{-\dagger} & \text{(massless, } m_F)\\[2pt]
(1+m_P)^{-1}\,\tilde D_{m_P}^{-\dagger} & (m_P)
\end{cases}
$$

So there is a single operator $D_m$; only the **parity** case adds $\tilde D_{m_P}$ (for massless
and $m_F$ everything is built from $D_m$).  The parity $(1+m_P)^{-1}$ prefactor cancels the
adjoint-kernel finite correction in the correlators (Eqs. 3.64--3.69), leaving none.

**Kernel** $K$ -- always the massless-form Noether kernel: $K^{nn'}(t)$ (spatial link),
$K^{t,t+1}(n)$ (temporal link) via `ConservedCurrent::apply_k`; adjoint $K^\dagger$ via
`apply_k_dag` (`conserved_current_claude.h:157`, spatial wrapper `apply_k_dag_wz` `:230`; accept
`std::pair<int,BaseLink>` / `std::pair<int,Idx>`).  $K$ is **mass-independent**: `apply_k` /
`apply_k_dag` read only the overlap's Zolotarev data (`D.C`, `D.A[m]`, `D.cp[m]`,
`D.lambda_max`, `D.M_DW`/`D.M_DWH`), never the additive `mass` -- so it is the same massless $K$
whichever overlap the `ConservedCurrent` wraps.

## 3. Estimators (mass-general)

All estimators below are written in $D_m^{-1}$ and $D_m^{-\dagger}$ (Sec. 2) with the massless
$K$/$(1-D_\text{ov})$ and **no mass-dependent prefactor**.  Per case: massless ($m=0$) recovers
Eqs. 3.52--3.57; $m_F$ uses $D_m=D_{m_F}$ (Eqs. 3.58--3.60); $m_P$ keeps the forward legs
$D_{m_P}^{-1}$ but replaces the dagger leg $D_m^{-\dagger}\to\tilde D_{m_P}^{-\dagger}$
(Eqs. 3.64--3.69).  For massless/$m_F$ the vector $(-)$ channel is the conjugate of the $(+)$
(Eq. 3.54), no extra solve; for $m_P$ it is an independent computation with $\tilde D_{m_P}$.

### 3.1 Disconnected (vector only) -- factorizes

$$
C_{V_{++},d}^{nn'}(0\to t)=T^{nn'}(0)\,T^{nn'}(t),
\qquad
T^{nn'}(t)\equiv\mathrm{tr}[D_m^{-1}K^{nn'}(t)]\approx\eta^\dagger K^{nn'}(t)\,\phi,
\quad \phi=D_m^{-1}\eta,
$$

(Eqs. 3.53, 3.65) estimated with $Z_2\times Z_2$ noise and time-spin dilution (as
`disc_claude.cu`).  The $(-)$ channel uses the dagger-leg single trace,

$$
C_{V_{--},d}^{nn'}(0\to t)=\tilde T^{nn'}(0)\,\tilde T^{nn'}(t),
\qquad
\tilde T^{nn'}(t)\equiv\mathrm{tr}[D_m^{-\dagger}K^{nn'\dagger}(t)],
$$

with $\tilde T=T^*$ for massless/$m_F$ (so the same $T$ suffices) and an independent dump for
$m_P$ (Eq. 3.67, dagger leg $D_m\to\tilde D_{m_P}$).  The program **dumps the raw per-config single-time traces** $T^{nn'}(t)$,
$T^{t,t+1}(n)$ (and $\tilde T$ in the parity case); products, gauge average, vacuum
subtraction, weighting and projection are done downstream (Secs. 4, 6).

### 3.2 Connected (vector / flavor) -- single source, source/sink split

$(+)$ channel (Eqs. 3.52, 3.64):

$$
\phi=K^{(\text{src})}\,D_m^{-1}\eta,
\qquad
\psi=D_m^{-\dagger}\,K^{(\text{snk})\dagger}\,\eta,
\qquad
C_{V_{++},c}=\langle\psi^\dagger\phi\rangle .
$$

Since $\psi^\dagger=\eta^\dagger K^{(\text{snk})}D_m^{-1}$,
$E[\psi^\dagger\phi]=\mathrm{tr}[D_m^{-1}K^{(\text{snk})}D_m^{-1}K^{(\text{src})}]$:
a single bilinear, exact, both legs forward $D_m^{-1}$, no disconnected contamination.
**Source side is free** -- $\phi_0=D_m^{-1}\eta$ is solved once per hit, the source
kernel applied afterwards.  **Sink side** is one $D_m^\dagger$ solve per sink time on a
composite source (Sec. 3.4).

$(-)$ channel (Eqs. 3.54, 3.66): same structure with $K\to K^\dagger$ on both legs,
$C_{V_{--},c}=\mathrm{tr}[D_m^{-\dagger}K^{(\text{snk})\dagger}D_m^{-\dagger}K^{(\text{src})\dagger}]$
($D_m\to\tilde D_{m_P}$ on these dagger legs for $m_P$).  Free for massless/$m_F$ (conjugate of
$(+)$); a second set of solves for $m_P$.

Flavor currents ($N_f=4,6$ only) need **no separate computation and no generators in code**:
the source/sink flavor trace factorizes to $\mathrm{tr}(T_r T_{r'})=\delta_{rr'}$ times the same
spatial/spin trace, so $\langle J_{r,+}(0)J_{r',+}(t)\rangle_F=-\delta_{rr'}C_{V_{++},c}$ (Eqs.
3.43--3.44) -- read off the vector-connected run.  The Hermitian SU($N_f/2$) generators with
$\mathrm{tr}(T_r T_{r'})=\delta_{rr'}$ (Eq. 3.4) are $T_r=\lambda_a/\sqrt2$ (Gell-Mann type;
$\sigma_a/\sqrt2$ for $N_f=4$); the generic $\lambda_a$ basis can be ported from
`cpn/.../julia_in_script2/header_claude.jl:18-48` (its `generators_` are the $\lambda_a$ with
$\mathrm{tr}=2$; the file's $0.5\mathrm{i}$ factor gives the anti-Hermitian su($N$) convention, so
divide by $\sqrt2$ and drop the $\mathrm{i}/2$ for the PDF normalization) -- needed only if
individual $r$ channels are ever wanted.

### 3.3 Axial (mixed orderings) -- same split with massless GW factors

$$
C_{A_{+-}}(0\to t)=\mathrm{tr}\big[D_m^{-1}K(0)\,(1-D_\text{ov}^\dagger)\,D_m^{-\dagger}K^\dagger(t)\,(1-D_\text{ov})\big]
\qquad(\text{Eqs. 3.55, 3.68}),
$$

$$
\phi_A=D_m^{-\dagger}\,K^\dagger(t)\,(1-D_\text{ov})\,\eta\ (\text{sink}),
\qquad
\psi_A=(1-D_\text{ov})\,K^\dagger(0)\,\rho_0\ (\text{source, free}),
\qquad \rho_0=D_m^{-\dagger}\eta,
$$

with $C_{A_{+-}}(0\to t)=\langle\psi_A^\dagger\phi_A\rangle$.  In the parity case the $K^\dagger(t)$
(sink) leg uses $\tilde D_{m_P}^{-\dagger}$ while the $K(0)$ leg (via $\rho_0$) keeps
$D_{m_P}$ (Eq. 3.68).  The GW factors $(1-D_\text{ov})$, $(1-D_\text{ov}^\dagger)$ are **always
massless** ($m=0$ operator), in every case.

**Only $C_{A_{+-}}$ is computed.**  Eq. 3.57, $C_{A_{+-}}(0\to t;U)=C_{A_{-+}}(t\to 0;U)$, is
trace cyclicity -- exact config-by-config and valid in every mass case (including parity, where
the vector currents have no such relation).  With the source-time average (the correlator is a
function of the separation $\Delta t$) this gives

$$
C_{A_{-+}}(\Delta t)=C_{A_{+-}}(N_t-\Delta t),
$$

so the second ordering is the time-reflection of the first -- obtained in post-processing, **no
independent solves**.  Hence the axial costs one set of sink solves, like the vector connected,
not two.  Implemented **as written**.

### 3.4 Composite sink source (one solve per sink time)

The sink-side solve acts on a composite source with the insertion-point sum folded in, so it is
**one solve per sink time**, never per insertion point:

- **`_ylmproj`** -- fold the deterministic $Y_{\ell m}$ weights:
  $\Psi^{(\ell_2 m_2)}(s)=D_m^{-\dagger}\sum_n\frac{A_n Y_{\ell_2 m_2}(\hat n)}{\kappa^{(0)}_{t,t+1}(n)}K^{t,t+1\,\dagger}(n,s)\eta$
  (one solve per channel per sink time), paired with the free
  $\Phi^{(\ell_1 m_1)}(s_0)=\sum_n\frac{A_n Y_{\ell_1 m_1}(\hat n)}{\kappa^{(0)}_{t,t+1}(n)}K^{t,t+1}(n,s_0)\phi_0$.
- **`_spproj` / `_tpproj` (diagonal)** -- realize the diagonal sum with stochastic
  insertion-point noise $\zeta_a$ ($a$ = link / site, $E[\zeta_a\zeta_b^*]=\delta_{ab}$):

$$
\Phi^\zeta(s_0)=\sum_a \zeta_a\sqrt{w_a}\,K^a(s_0)\,\phi_0\ (\text{free}),
\qquad
\Psi^\zeta(s)=D^{-\dagger}\sum_a \zeta_a\sqrt{w_a}\,K^{a\dagger}(s)\,\eta\ (\text{one solve}),
$$

  giving $E_{\zeta,\eta}[\Psi^\zeta(s)^\dagger\Phi^\zeta(s_0)]=\sum_a w_a\,\mathrm{tr}[K^a(s)D^{-1}K^a(s_0)D^{-1}]$;
  off-diagonal terms average to zero, variance controlled by the number of $\zeta$-hits.

Because $\Phi$ supplies all source times for free, solving $\Psi$ at $n_s$ sink times yields all
$\Delta t$ with $n_s$ source-time samples.

## 4. Projections, geometry, normalization

### 4.1 Section-4 observables (geometric weights applied in-program)

$$
G_s(t)=\frac{1}{4\pi}\sum_{\langle n,n'\rangle}\frac{A_{nn'}}{\kappa^{(0)\,2}_{nn'}}\langle J^{nn'}(0)J^{nn'}(t)\rangle,
\qquad
G_t(t)=\frac{1}{4\pi}\sum_{n}\frac{A_{n}}{\kappa^{(0)\,2}_{t,t+1}(n)}\langle J^{0,1}(n)J^{t,t+1}(n)\rangle,
$$

$$
G^{t}_{\ell_1 m_1;\ell_2 m_2}(t)=\frac{1}{4\pi}\sum_{n_1,n_2}
  \frac{A_{n_1}Y_{\ell_1 m_1}(\hat n_1)}{\kappa^{(0)}_{t,t+1}(n_1)}
  \frac{A_{n_2}Y_{\ell_2 m_2}(\hat n_2)}{\kappa^{(0)}_{t,t+1}(n_2)}
  \langle J^{0,1}(n_1)J^{t,t+1}(n_2)\rangle .
$$

For the vector $(+)$ current $\langle JJ\rangle=-C_{V_{++},c}+C_{V_{++},d}$ (and the $(-)$
analogue).  The geometric weights and the real $Y_{\ell m}$ (from `GetYlm`) are applied
**inside the compiled programs**; the notebooks only gauge-average, vacuum-subtract, combine
and fit.

**Normalization convention.**  The $C$'s are bare traces; the PDF relations carry overall
factors, e.g. $\tfrac{2}{N_f}\langle J_{V,+}(0)J_{V,+}(t)\rangle_F=-C_{V_{++},c}+C_{V_{++},d}$
(Eq. 3.39) and the disconnected loop $L=-N_f\,T$.  These $2/N_f$, $-N_f$ factors are applied at
the analysis stage; the programs output the bare $C_{V_{\pm\pm},c}$, $C_{V_{++},d}$,
$C_{A_{\pm\mp}}$, $T$.

### 4.2 Geometric quantities (already in code)

| Symbol | Meaning | Accessor |
|---|---|---|
| $\kappa^{(0)}_{nn'}$ | free-field spatial-link coupling | `DiracOp::kappa[il]` (`dirac_simp.h:355-360`) |
| $A_{nn'}$ | dual area of edge $(n,n')$ | `lattice.link_volume[il]` (`s2n_simp.h:29`) |
| $A_n$ | dual (Voronoi) area of site $n$ | `lattice.dual_areas[s]` (`s2n_simp.h:38`) |
| $\kappa^{(0)}_{t,t+1}(n)$ | temporal-link coupling (uniform in $t$, per site) | per-site array (candidate `dual_areas[ix]`); pin when coding |
| $Y_{\ell m}(\hat n)$ | real spherical harmonic | `lattice.GetYlm(s,l,m)` after `UpdateYlm(l_max)` (`s2.h:55-56`) |

**Data flow.**  GPU dump ($T$) $\to$ disc post-proc ($G^{disc}$ per config, weighted); GPU
connected ($G^{conn}$ per config, weighted, per `--current`); both $\to$ notebooks.  The driver
runs the GPU stages over all 27 ensembles.

**CLI conventions.**

- **Valence mass**: complex `--mass-re`/`--mass-im` = the propagator mass.  $0\Rightarrow$
  massless, real$\Rightarrow m_F$, imaginary$\Rightarrow m_P$.  The executable forms $D_m$ (and,
  for the parity dagger leg, $\tilde D_{m_P}=D_\text{ov}+m_P/(1-m_P)$) per Sec. 2; no kernel flag,
  no kernel branching.
- **Ensemble (sea) selection**, decoupled from the valence mass: the config directory (or the
  sea-mass identifier that builds it) is its own CLI argument, so a massless-valence run can
  read an $m_F$ ensemble.  The config path matches `hmc_w_mass_claude.cu`'s `dir3`
  (`Nf{Nf}_gsq{gsq}at{at}nu0{nu0}mRe{}mIm{}nt{Nt}L{N_REFINE}`, `:186`) with the **sea** mass as
  `mRe`/`mIm`.
- **Free-field mode** -- if the ensemble/config-dir argument is **omitted**, the program runs
  the **free case**: trivial gauge field $U=1$ (no read, no gauge fluctuation), a single
  deterministic "config".  This is a free-field check (cf. `check_conserved_current_claude.cu`),
  available for every program and every valence mass (so each mass case can be checked against
  the free background).  Output is tagged `free` in the dir/filename.
- **`--current vector|axial`** for the connected programs (one per run; no inversion reuse
  across currents).  Projection (`sp`/`tp`/`ylm`) is selected by which executable.
- **Output**: one HDF5 file per config $k$, `HighFive::File::Truncate`, resume sentinel (as
  `disc_claude.cu:272-286`).  Filename/dir encodes **both** sea mass (ensemble) and valence
  mass + current + projection (Sec. 7 item).
- **Noise**: `nhits=1`, `t_block=8` (time-spin dilution, `disc_claude.cu:164-165`).  Connected
  programs use all-to-all $\eta$; diagonal projections add $\zeta$ insertion-point noise.
- **Operator-definition layout**: group the operator construction (`WilsonDirac DW`, the overlap
  operators $D_m$ and -- parity -- $\tilde D_{m_P}$, `ConservedCurrent kop`) in the **same block
  order as `hmc_w_mass_claude.cu`** so it can be eyeballed side-by-side against the HMC code.

**Compile-time** (inherit `disc_claude.cu`): `N_REFINE=1`, `Nt=128`, `NPARALLEL_DUPDATE=1`,
`TOL_INNER=1e-15`, `TOL_OUTER=1e-14`.

**Reused infrastructure** (no operator changes): complex-mass overlap `Overlap<WilsonDirac>`
from `overlap_wmass_claude.h` (`Overlap D(DW, mass, 21)`; reduces to massless at `mass=0`); its
`mult`$=(D_\text{ov}+m)v$ (`:334`), `adj`$=(D_\text{ov}+m)^\dagger v$ (`:366`), GW-shortcut
`DHD`$=(D+m)^\dagger(D+m)$ (`:371`, general complex $m$), `DDH=DHD` (`:392`, valid since
$D_\text{ov}+m$ is normal); `apply_k`/`apply_k_dag` (`conserved_current_claude.h`); CG chains
`op_DH`/`op_DHD` and the `DDH` dagger-leg solve; `from_cpu`/`solve`; `FermionVector`
(`fill_z2_source`, `time_spin_dilution`, `dag`, `valence_claude.h`); `GaugeExt::read`
(`disc_claude.cu:282`); lattice geometry (Sec. 4.2).

## 6. Implementation chunks

### Disconnected dump

**Chunk 1 -- boilerplate + construction.**  Copy `disc_claude.cu` boilerplate (`Comp`, type
aliases, `ParseArgs`, GPU/lattice/DW/Gauge setup); use `overlap_wmass_claude.h`
(`Overlap D(DW, mass, 21)`); add `--mass-re`/`--mass-im` and the ensemble/config-dir argument
to `ParseArgs`; add `#include "includes/conserved_current_claude.h"` and
`ConservedCurrent<Fermion> kop(D)`.
Files: `jj_disc_claude.cu`.

**Chunk 2 -- enumerate + dump layout.**  Enumerate spatial links $(s, lk)$ over `base.links`
and temporal sites $(n, s)$; HDF5 keys `spatial/{ix0}/{ix1}/{real,imag}` (len $N_t$),
`temporal/{n}/{real,imag}` (len $N_t$), plus `*_dag/...` for $\tilde T$ in the parity case;
output dir + resume sentinel.
Files: `jj_disc_claude.cu`.

**Chunk 3 -- stochastic loop + dump.**  Per config, per hit, per dilution block: draw diluted
$\eta$, solve $\phi=D_m^{-1}\eta$, accumulate $T^{lk}(s)\mathrel{+}=\eta^\dagger K^{lk}(s)\phi$
and $T^{n}(s)\mathrel{+}=\eta^\dagger K^{t,t+1}(n,s)\phi$; divide by `nhits`; write raw $T$.  For
$m_P$ also solve $\tilde\phi=\tilde D_{m_P}^{-\dagger}\eta$ and dump
$\tilde T\mathrel{+}=\eta^\dagger K^\dagger\tilde\phi$.  No correlator formed.  **Free-field
mode** (no ensemble id): skip the config read, set $U=1$, run once.
Files: `jj_disc_claude.cu`.

### Connected (GPU)

**Chunk 4 -- boilerplate + `--current`.**  As Chunk 1 for the three `jj_conn_*proj` programs;
all-to-all $\eta$; add `--current vector|axial`.  Construct $D_m$ (and $\tilde D_{m_P}$ for the
parity dagger leg) per Sec. 2 (two `Overlap` instances sharing `DW`/`update(U)`, or a `mass`
switch).
Files: `jj_conn_spproj_claude.cu`, `jj_conn_tpproj_claude.cu`, `jj_conn_ylmproj_claude.cu`.

**Chunk 5 -- per-config loop.**  Per hit: base solve(s) $\phi_0=D_m^{-1}\eta$ (and
$\rho_0=D_m^{-\dagger}\eta$ for axial).  Build the free source-side vectors; build the
composite sink source (Sec. 3.4: $Y_{\ell m}$ fold for ylm, $\zeta$ noise for sp/tp), one
$D^\dagger$ solve per sink time; contract $\psi^\dagger\phi$ over source times into $G(\Delta t)$
for the selected current.  Vector: $C_{V_{++},c}$, plus $C_{V_{--},c}$ (conjugate for
massless/$m_F$; separate $\tilde D_{m_P}$ solves for $m_P$).  Axial: $C_{A_{+-}}$ **only**
($C_{A_{-+}}$ is the reflection $\Delta t\to N_t-\Delta t$, done in post-processing -- Sec. 3.3).
Average over $\eta$ (and $\zeta$) hits.  **Free-field mode** (no ensemble id): skip the config
read, set $U=1$, run once.
Files: the three `jj_conn_*proj_claude.cu`.

**Chunk 6 -- output.**  HDF5 per config; filename encodes sea mass, valence mass, `--current`;
datasets: sp/tp $\to$ $G(t)$ len $N_t$; ylm $\to$ per $(ch_1,ch_2)$ len $N_t$; vector writes
$C_{V_{++},c}$ (and $C_{V_{--},c}$ for $m_P$), axial writes $C_{A_{+-}}$ only ($C_{A_{-+}}$ via
the $\Delta t\to N_t-\Delta t$ reflection in analysis).  Resume sentinel.
Files: the three `jj_conn_*proj_claude.cu`.

### Disconnected post-processing

**Chunk 7 -- geometry + read.**  Reconstruct the lattice (Sec. 4.2), build the weight arrays
$w^{sp}_{lk}$, $w^{tp}_n$, $w^{ylm}_{n,(\ell m)}$; enumerate and read the dump files.
Files: `jj_disc_spproj_claude.cu`, `jj_disc_tpproj_claude.cu`, `jj_disc_ylmproj_claude.cu`.

**Chunk 8 -- projection + output.**  Per config, apply weights and form the projected products
(source-time averaged): sp/tp $\to$ $\sum_a w_a\frac1{N_t}\sum_{s_0}T^a(s_0)T^a(s_0+t)$ with
per-link/site weighted singles kept for the vacuum term; ylm $\to$
$\tilde T^{(\ell m)}(s)=\sum_n w^{ylm}_{n,(\ell m)}T^{t,t+1}(n,s)$, then
$D^{ylm}_{(\ell_1 m_1),(\ell_2 m_2)}(t)=\frac1{N_t}\sum_{s_0}\tilde T^{(\ell_1 m_1)}(s_0)(\tilde T^{(\ell_2 m_2)}(s_0+t))^*$.
Write per config in the connected-like layout (parity uses $\tilde T$ for the $(-)$ channel).
Files: the three `jj_disc_*proj_claude.cu`.
